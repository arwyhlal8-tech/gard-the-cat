# 7 Day Cat

A short,  fanny visual novel built with Ren'Py. Guard the cat, follow the rules... and survive the night!

---

# About The Game
You are tasked with watching over a cute cat while the owner is away. But this isn't just a regular cat-sitting job. Read the notes carefully, keep the house safe, and make the right choices to discover different ending


#Technical Details
* Engine: Ren'Py (Python)
* **Platforms**: Windows / Mac / Linux
